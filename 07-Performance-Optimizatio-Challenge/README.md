# Exercise 07 – Performance Optimization Challenge

## Overview

This exercise focused on identifying and improving the performance of a slow Python function used in an e-commerce application. The function searches for product pairs that match a target price but performs poorly because it compares every product with every other product.

## Objective

- Identify the performance bottlenecks.
- Use AI to analyze the code.
- Suggest and document optimization techniques.
- Compare performance before and after optimization.
- Reflect on the lessons learned.

## Files Included

- README.md

- Reflection.md

## Key Learning Outcomes

- Understanding algorithm efficiency.
- Identifying performance bottlenecks.
- Using efficient data structures.
- Measuring performance before and after optimization.
- Using AI to support software optimization and debugging.
