# Reflection

This exercise taught me that inefficient algorithms can have a major impact on application performance. I learned that nested loops often create performance bottlenecks when working with large datasets.

I also learned that using better data structures, such as dictionaries, can greatly improve performance. Measuring execution time before and after optimization is important because it confirms whether the changes were successful.

In future projects, I will analyze algorithms carefully, profile my code before making changes, and choose efficient data structures to improve performance.
