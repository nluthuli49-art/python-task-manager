# Project Information

## Project Name
Python Task Manager

## Description
Python Task Manager is a command-line application developed in Python that helps users create, organize, update, and manage daily tasks. The application stores tasks in a JSON file, making it simple to save and retrieve task information between sessions.

## Purpose
The purpose of this project is to demonstrate the use of Python programming concepts such as object-oriented programming, file handling, JSON data storage, and modular programming while providing a practical task management solution.

## Features
- Create new tasks
- View all tasks
- Update existing tasks
- Mark tasks as completed
- Delete tasks
- Store tasks using JSON
- Simple command-line interface

## Technologies Used
- Python 3
- JSON
- Object-Oriented Programming (OOP)
- Command Line Interface (CLI)
