# Frequently Asked Questions (FAQ)

## What is Python Task Manager?

It is a command-line application used to organize and manage daily tasks.

---

## Who can use this application?

Anyone who wants a simple task management system.

---

## Where are tasks stored?

Tasks are stored inside the `tasks.json` file.

---

## Can I edit a task?

Yes. Existing tasks can be updated at any time.

---

## Can I delete tasks?

Yes. Tasks can be permanently deleted.

---

## How do I mark a task as completed?

Select the **Complete Task** option from the menu.

---

## What happens if I close the application?

Your tasks remain saved in the JSON file.

---

## Why aren't my tasks saving?

Ensure the application has permission to write to `tasks.json`.

---

## What version of Python is required?

Python 3.8 or newer.

---

## Can this project be expanded?

Yes. Future improvements include:

- User accounts
- Notifications
- Search functionality
- Categories
- GUI interface
- Cloud storage

---

## Is this project open source?

Yes. It can be modified and improved for educational purposes.
