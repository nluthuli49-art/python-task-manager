# User Guide

## Introduction

This guide explains how to use the Python Task Manager application.

---

# Requirements

Before running the application, ensure you have:

- Python 3.8+
- The project files
- Visual Studio Code (recommended)

---

# Running the Program

Open a terminal inside the project folder.

Run:

```bash
python app.py
```

---

# Creating a Task

1. Start the application.
2. Select **Add Task**.
3. Enter:
   - Task title
   - Description
   - Due date
   - Priority
4. Save the task.

---

# Viewing Tasks

1. Select **View Tasks**.
2. All saved tasks will appear.

---

# Editing a Task

1. Select **Edit Task**.
2. Choose the task.
3. Update the required information.
4. Save your changes.

---

# Completing a Task

1. Select **Complete Task**.
2. Choose the task.
3. The task status changes to **Completed**.

---

# Deleting a Task

1. Select **Delete Task**.
2. Choose the task.
3. Confirm deletion.

---

# Common Problems

## Tasks are not saving

Verify that `tasks.json` exists and is writable.

## Program won't start

Ensure Python is installed correctly.

## Missing files

Make sure all project files remain in the same folder.

---

# Best Practices

- Regularly back up the JSON file.
- Keep task descriptions clear.
- Mark completed tasks promptly.
- Delete unnecessary tasks to stay organized.
